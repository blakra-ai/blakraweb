THE PROBLEM

Managers of several locations usually assemble that picture from exports and messages. The same figure arrives in a different format from each place, and the version on screen is rarely the current one.

THE DESIGN
01

Four figures sit at the top — revenue, orders, conversion and average order value — each with the period it is compared to.

02

Revenue is drawn over seven days, and the table below stays filtered to the same range.

03

Orders can be filtered by store and status, with the count of matches stated above the list.

04

Loading and empty states are designed, because a quiet morning is a normal state for a dashboard.

05

Table text is set at a readable size first; density is added around the type rather than into it.

NOTE

Concept work. Screens are design mockups, not a client deployment.
