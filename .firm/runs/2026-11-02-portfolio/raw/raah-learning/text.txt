THE PROBLEM

A paper exam becomes data only after someone types it in. By the time a teacher sees which topic failed, the class has moved on, and the same mistake appears in the next test.

THE DESIGN
01

The exam screen keeps timer, question number and progress in one bar.

02

Answers save as they are selected, and the screen states when the last save happened.

03

The results view compares topics rather than ranking students against each other.

04

Weak topics are listed with the questions that produced them, so the teacher can reread the question.

05

Question text is set larger than the labels around it, because it is read under time pressure.

NOTE

Concept work. Screens are design mockups, not a client deployment.
