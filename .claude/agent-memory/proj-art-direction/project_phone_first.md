**How to apply:** review every section at 390 and 360 first; target ≤ 1.3 screens per section, CSS-only motion on phones (scroll timelines, ripples), no GLB by default; desktop sticky holds (Stage) must not leave dead bands on phones. See [[art-direction-review]].
