## Rules that matter here
- GSAP 3.15 is free for commercial use including former Club plugins [https://gsap.com/standard-license/, terms 2025-05-30, checked 2026-11-01].
- Lenis + GSAP: `lenis.on('scroll', ScrollTrigger.update)`, `gsap.ticker.add(t => lenis.raf(t * 1000))`, `gsap.ticker.lagSmoothing(0)`, one loop only; nested scroll areas use `data-lenis-prevent` [https://github.com/darkroomengineering/lenis, 1.3.27, 2026-11-01].
- No pins, no snapping, no `backdrop-filter` over the canvas; the page height never changes while reading [project doc: .firm/charter.md conventions].
- three r181 brightened rough PBR (indirect specular); r182 deprecated PCFSoftShadowMap; r187 changes PMREM, so do not upgrade past 0.186 without re-checking [https://github.com/mrdoob/three.js/wiki/Migration-Guide, 2026-11-01].
- R3F: prefer `frameloop="demand"` + `invalidate()` for static scenes; drive dpr with PerformanceMonitor [https://r3f.docs.pmnd.rs/advanced/scaling-performance, 2026-11-01].
- CSS scroll-driven animations: Chrome 115+, Safari 26; Firefox flag-only (secondary claim) → progressive enhancement only [https://developer.chrome.com/docs/css-ui/scroll-driven-animations, 2026-11-01].
- Scroll-jacking harms control and task success [NNG Scrolljacking 101, 2026-11-01].

## Known pitfalls in this repo
- Absolute bone rotations destroy a real rig's rest pose; Figure.tsx applies gaze relative to rest and in world space (hair sway) — keep it that way for any new bone driver.
- A rigged export's bounds cannot be read from the mesh buffer (cm units under a 0.01 node): loadFigure.ts updates skeletons and uses precise skinned bounds; eye sockets give the head length in navigator-adopt.mjs.
- Injected spheres once had inverted winding (the shader showed the inside, uniform tan); spherePrim in navigator-adopt.mjs is counter-clockwise now.
- GSAP ScrollTrigger once cost a full-page layout per scroll (removed on 2026-10-26; reflow.ts replaced it); never read getBoundingClientRect in a ticker.
- Dock ↔ world hand-off was a cut until HANDOFF became symmetric (World.tsx); the scrub probe (scratchpad scrub.mjs pattern, `globalThis.__nav` in dev) is the evidence.
